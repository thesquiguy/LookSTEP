# Documentation image provenance

The two JPEG files in this directory are original LookSTEP application
screenshots captured from a Raspberry Pi STEP assembly supplied for local QA.
On 2026-07-22, the project author attested that the source STEP files were
properly licensed, clean-room-safe, and not V1 or work resources. The source
STEP file is not committed.

The screenshots contain only the app/Finder presentation of that licensed
fixture. They were cropped and resized for the public README; no third-party
photograph, logo artwork, or UI design asset was incorporated.
