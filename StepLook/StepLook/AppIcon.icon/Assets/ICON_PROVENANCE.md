# LookSTEP app icon provenance

All bitmap layers in this directory are original LookSTEP project artwork:

- `LookSTEPBackground.png`: violet rounded-square background.
- `01-document 3.png`: white STEP document layer.
- `02-step.png`: STEP wordmark layer.
- `03-cad-solid 3.png`: blue CAD solid layer.

The artwork was created for LookSTEP, assembled with Apple Icon Composer, and
is distributed under the repository's MIT License. It does not incorporate
third-party logos, trademarks, stock artwork, or generated CAD source files.
